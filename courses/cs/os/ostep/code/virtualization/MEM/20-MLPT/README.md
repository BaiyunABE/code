### Make Table Smaller: Multi-level Page Table

#### Virtual Address
```text
+-------+-------+------+
|PDIndex|PTIndex|offset|
+-------+-------+------+
|<-----VPN----->|
```
#### Multi-level Page Table
```text
PDBR
+---+      PFN 200
|200|----->+-----+---+
+---+      |valid|PFN|
           +-----+---+
           | ... |...|    PFN 201             +---+------+
    +----->|  1  |201|--->+-----+----+---+    |PFN|offset|--->Physical Address
    |      | ... |...|    |valid|prot|PFN|    +---+------+
    |      +-----+---+    +-----+----+---+      ^    ^
    |                     | ... |... |...|      |    |
    |       +------------>|  1  | rw |100|------+    |
    |       |             | ... |... |...|           |
    |       |             +-----+----+---+           |
+-------+-------+------+                             |
|PDIndex|PTIndex|offset|-----------------------------+
+-------+-------+------+
```
