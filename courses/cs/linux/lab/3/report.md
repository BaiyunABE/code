## 三、实验要求
利用`netstat --statistics`编写 Shell 脚本，**每分钟采集一次 TCP 收发报文统计**，输出格式：`当前时间 分钟发送报文 分钟接收报文 收发合计 状态标记(+ / 空格 / -)`；

标记规则：

1. 本期总报文 − 上期总报文＞10 → 符号`+`
2. 差值在`[-10,10]`之间 → 空格
3. 差值＜−10 → 符号`-`

## 四、程序设计思路
1. 封装函数`get_tcp_stats()`：执行`netstat --statistics`，正则筛选 TCP 接收、发送两行统计，`expr`正则截取数值，返回接收总数与发送总数；
2. 程序初始化：首次调用函数获取系统 TCP 累计初值，记录初始 `recv`、`send`，基准总量`total=0`；
3. 循环主体：休眠 60 秒→采集新一轮累计值→累计差值 = 当前累计 − 上轮累计，得到本分钟收发增量；
4. 增量求和得到分钟总流量，对比上一分钟总流量差值，按规则判定末尾符号；
5. `printf`格式化打印一行报表，刷新保存本轮累计值与本轮总流量，进入下一轮循环。

## 五、核心代码展示
```shell
#!/bin/bash

get_tcp_stats() {
	local info=`netstat --statistics | grep -E "[0-9]+ segments .*"`
	local recv=`expr "$info" : '.* \([0-9]\+\) segments received.*'`
	local send=`expr "$info" : '.* \([0-9]\+\) segments sent out.*'`
	
	echo "$recv $send"
}

init=`get_tcp_stats`
recv=`expr "$init" : '\(.*\) .*'`
send=`expr "$init" : '.* \(.*\)'`
unset init
total=0

while true; do
	sleep 60

	now=`date +"%Y-%m-%d %H:%M"`
	
	curr=`get_tcp_stats`
	curr_recv=`expr "$curr" : '\(.*\) .*'`
	curr_send=`expr "$curr" : '.* \(.*\)'`
	
	delta_recv=`expr $curr_recv - $recv`
	delta_send=`expr $curr_send - $send`
	delta_total=`expr $delta_recv + $delta_send`
	
	symbol=" "
	diff=`expr $delta_total - $total`
	if [ $diff -gt 10 ]; then
		symbol="+"
	elif [ $diff -lt -10 ]; then
		symbol="-"
	fi
	
	printf "%s%6s%6s%6s%6s\n" "$now" "$delta_send" "$delta_recv" "$delta_total" "$symbol"
	
	recv=$curr_recv
	send=$curr_send
	total=$delta_total
done
```

## 七、总结

1. 反引号实现命令替换，`grep -E`使用扩展正则过滤数据，`expr`结合分组正则完成数字提取。
2. `netstat` 统计为开机累计数据，通过前后数值作差，才能得到每分钟实际收发报文增量。
3. `while` 搭配 `sleep 60` 实现一分钟定时采样，`if` 多分支完成末尾标识`+/-/ `的逻辑判定。
